# Windows tests (target `windows`)

Questions the reference specification, revision 10 does not settle and that only a test on Windows can settle. They run
in a disposable virtual machine, as the reference specification's own tests did (dll §11). Results carry the tag
**[VM]** and the source **"yakbd VM run 1, 2026-11-22"** (Windows 11 Pro 25H2, build 26200, x64; the tool's
`yakbd-wincheck` probes, 64-bit and 32-bit; raw output kept with the run, `results-64.txt`, `results-32.txt`).

## Runner environment (lesson of run 1)

`LoadKeyboardLayoutW` returns NULL in a session without an interactive desktop (for example PowerShell Direct into the
guest). The probes must run in the console session with an input desktop: run 1 used a scheduled task with an
interactive logon and highest privileges. The tool's runner now refuses to start without an input desktop. A failed
load in a run must therefore first be checked against this before it is read as a result.
